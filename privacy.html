Privacy Policy

This Privacy Policy explains how Hermes Workspace Automation accesses and uses Google user data. The application is a private automation tool used by its owner and is not offered as a public service.

Google data accessed

After the owner grants permission through Google OAuth, the application may access Google Drive files and Google Sheets required for owner-requested automation tasks. Access is limited to the permissions granted by the owner.

How data is used

Google user data is used only to perform requested functions, such as creating, reading, updating, and organizing authorized spreadsheets and Drive files. It is not used for advertising or profiling.

Data sharing and sale

Google user data is not sold, rented, or shared with independent third parties. Data is transmitted to Google APIs and the application's secured execution environment only as needed to perform the requested automation.

Storage and security

OAuth credentials may be stored in a restricted environment so authorized automation can continue. Reasonable technical controls are used to restrict access. The application does not collect or store the owner's Google password.

Retention and deletion

Operational data and credentials are retained only as needed for the private automation. The owner can stop future access by revoking the application's permission from the Google Account security settings. Locally stored credentials can also be deleted from the application's host.

Google API Services User Data Policy

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
